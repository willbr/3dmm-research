The SDL audio adapter additionally decodes GSM 6.10 WAV49 and MP3-in-WAV.
Both dependencies are linked statically; no runtime codec installation is needed.

libgsm 1.0.24: https://www.quut.com/gsm/gsm-1.0.24.tar.gz
SHA256 a3c40c6471928383f4abfcb2e8f24012a1f562be2f17b8d672145d5986681a92
Copyright and terms: libgsm-LICENSE.txt.
The CMake integration generates a private header that replaces longword and
ulongword with int32_t and uint32_t. This keeps GSM arithmetic fixed at 32 bits
on Windows, Linux and macOS. The downloaded source remains unchanged.
WAV49 is enabled; only the decoder and its supporting DSP sources are built.

as licenses/audio-codecs-LICENSE.txt, including builds without bundled MIDI.
